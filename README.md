# Charan Blood Donation Camp Website

A responsive static website built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build tools are required.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation, current year, and demo form interaction

## Before publishing
- Replace the demo form behavior with a secure backend or form service.
- Add your real camp date, venue, organizer contact details, and privacy notice.
- Confirm all donor eligibility and medical guidance with the authorized blood bank.
- Images are loaded from Unsplash and require an internet connection.
